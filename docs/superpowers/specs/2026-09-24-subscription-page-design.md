# Страница подписки → «Управление подпиской» (этап 5 редизайна)

- Дата: 2026-09-24
- Статус: черновик, ждёт ревью
- Родительская спецификация: `docs/superpowers/specs/2026-09-24-cabinet-ux-redesign-design.md` (раздел 3 откладывал этот этап сюда)
- Область: `src/pages/Subscription.tsx` (`/subscriptions/:id`) и компоненты, которые из неё выделяются

## 1. Проблема

`Subscription.tsx` — 1813 строк и несколько экранов прокрутки на телефоне. На одной
странице смешаны три вещи:

- **подключение** — кнопка «Подключить устройство», ссылка подписки, «Мои
  устройства» (после этапа 3 всё это есть на вкладке «Устройства»);
- **статус** — трафик, дни, посекундный отсчёт, локации (пользователю виден
  технический «Default-Squad»);
- **управление** — автопродление (до трёх переключателей: с баланса, СБП, Lava),
  продление, докупка устройств/трафика, серверы, перевыпуск, пауза суточного
  тарифа, удаление истёкшей подписки.

Отдельная ловушка — **автопродление с баланса**. Бот за N дней до окончания
списывает оплату с баланса. После этапа 2 люди платят сразу за подписку, денег
на балансе обычно нет — и при включённом «Автопродлении» подписка всё равно
заканчивается. Кнопка обещает то, что не произойдёт.

## 2. Цели

- Страница отвечает на «что с моей подпиской и что с ней можно сделать», а не
  дублирует вкладку «Устройства».
- Одно главное действие («Продлить» / «Сменить тариф») видно без прокрутки.
- Автопродление честно говорит, пройдёт ли оно: сколько на балансе и хватит ли.
- Редкие и технические вещи (локации, ссылка для ручной настройки) не мешают, но
  доступны.
- Поведение всех действий (запросы, мутации, окна докупки, SBP/Lava, пауза,
  перевыпуск с ограничением частоты) не меняется.

## 3. Не входит

- Изменения бэкенда. В частности, кабинет не получает от бота срок и цену
  автоплатежа (см. 5.3) — обходимся без них.
- Логика SBP/Lava-автоплатежа, окон докупки (`sheets/*`), паузы суточного
  тарифа, перевыпуска — переносятся как есть.
- Переименование сквадов/локаций — делается в панели Remnawave.
- Мультитарифный список `/subscriptions` — не меняется.

## 4. Решения владельца (2026-09-24)

1. Страница становится **только «Управлением»**: подключение и список устройств —
   на вкладке «Устройства», здесь — ссылка туда.
2. Автопродление с баланса показывается **честно, с балансом**: переключатель
   остаётся, рядом — хватит ли денег и кнопка пополнения.
3. Подход — **разложить страницу на секции-компоненты** (перенос кода, как с
   `DevicesPanel` на этапе 3), `Subscription.tsx` становится тонким контейнером.

## 5. Дизайн

### 5.2 Компоненты

Новые файлы в `src/components/subscription/manage/` — каждый получает то, что
ему нужно, пропсами (подписку, данные запросов, колбэки мутаций), а запросы и
мутации **остаются в `Subscription.tsx`**: это главный источник регрессий, и их
перенос не нужен для цели этапа.

| Компонент | Ответственность |
|---|---|
| `StatusSection.tsx` | секция 1 |
| `AutopaySection.tsx` | секция 3: обёртка вокруг перенесённых блоков автопродления + `BalanceAutopayHint` |
| `BalanceAutopayHint.tsx` | честная строка про баланс (5.3) |
| `ExtrasSection.tsx` | секция 4 |
| `DetailsSection.tsx` | секция 5, свёрнута |
| `DangerSection.tsx` | секция 6 |

`src/utils/autopayFunding.ts` — чистая функция для 5.3.

Разметка блоков переносится из `Subscription.tsx` без изменений, кроме: удаления
перечисленного в 5.1 и обёрток секций (заголовок секции + карточка).

### 5.3 Честное автопродление с баланса

Кабинет не знает срок и цену автоплатежа: бот выбирает период по цепочке
«выбор в подписке → `DEFAULT_AUTOPAY_PERIOD_DAYS` → самый короткий период
тарифа → 30 дней», и этого нет в API. Поэтому сравниваем баланс с **самой
дешёвой ценой продления** (`GET /cabinet/subscription/renewal-options` для этой
подписки — тот же запрос, что на странице продления):

- `autopayFunding(balanceKopeks, minRenewalKopeks)`:
  - `minRenewalKopeks` неизвестна → `'unknown'` (строки нет — не выдумываем);
  - баланс < минимальной цены → `{ state: 'short', missingKopeks }`;
  - иначе → `{ state: 'ok' }`.
- Под переключателем, **только когда автопродление включено**:
  - `short` — «Спишем с баланса за {N} дня до окончания. Сейчас на балансе
    {баланс} — продление не пройдёт. Пополните заранее.» + кнопка «Пополнить
    баланс» → `/balance/top-up?amount={missing, руб., вверх}&returnTo=/subscriptions/{id}`
    (обычное пополнение, не режим «оплата подписки»: человек осознанно кладёт
    деньги на баланс для автоплатежа);
  - `ok` — «Спишем с баланса за {N} дня до окончания. На балансе {баланс}.»
- При выключенном автопродлении — одна строка-пояснение «Продлевать
  автоматически с баланса за {N} дня до окончания».
- `N` — `subscription.autopay_days_before`.

Для суточного тарифа и триала переключатель, как и сейчас, не показывается.

### 5.4 Тексты

Неймспейс `manage.*` в `ru.json`/`en.json` (паритет — `locales.test.ts`),
`zh`/`fa` — английский текст. Заголовки секций: «Статус» не пишем (карточка
первая), «Автопродление», «Дополнительно», «Подробности», «Прочее»;
«Ручная настройка» вместо «Ссылка подписки»; «Устройства: {used} из {max}».

## 6. Тесты

- `autopayFunding`: неизвестная цена, нехватка (с суммой), достаточно.
- `BalanceAutopayHint`: включено + нехватка → текст и ссылка на пополнение с
  суммой и `returnTo`; включено + хватает → без кнопки; выключено → пояснение.
- `StatusSection`: ссылка «Устройства» ведёт на `/connection?sub={id}`; полоса
  трафика только у лимитного тарифа; нет кнопки «Подключить устройство».
- `DetailsSection`: свёрнута по умолчанию; ссылка подписки скрыта при
  `hide_subscription_link`.
- Существующие тесты страницы/окон остаются зелёными.

Ручная проверка — на рабочем бэкенде через dev-прокси, 375 px: порядок секций,
«Продлить» видно без прокрутки, строки автопродления в обоих состояниях (баланс
0 ₽ → «продление не пройдёт»), окна докупки открываются, перевыпуск и
«Подробности» работают.

## 7. Риски

- **Регрессии при переносе** — самый большой риск. Смягчение: запросы и мутации
  не переезжают; разметка переносится механически; после каждой секции —
  type-check, тесты и ручной прогон.
- **Конфликты с апстримом** — `Subscription.tsx` в апстриме меняется часто;
  владелец согласен. Разбиение на секции делает будущие конфликты меньше и
  локальнее.
- **Минимальная цена продления ≠ фактической цене автоплатежа** — строка «хватает»
  может оказаться оптимистичной, если бот продлит на более длинный период.
  Поэтому в `ok` не пишем «хватит», только «На балансе {баланс}»; уверенно
  утверждаем только нехватку.
